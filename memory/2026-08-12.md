### Key Design Decisions
- DS-EO never writes to OpenClaw internal state — only reads and classifies
- Reconciliation loop is agent-triggered (not periodic polling) to avoid overhead
- Error patterns use substring matching for resilience against message format changes
- Recovery procedures are explicit state→action mappings, tested in controlled scenarios
