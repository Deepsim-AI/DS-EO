### Root Cause of Bug #2 (TUI Deadlock)

1. Compaction starts → TUI receives `phase="finishing"` → sets `activityStatus = "finishing context"`
2. User aborts + starts new run simultaneously → `activeChatRunId` switches to new run
3. Old lifecycle events arrive with old runId → `hasConcurrentActiveRun()` blocks all updates
4. Result: **deadlock** — can't clear the stuck state, and second abort is also blocked

### Upstream Patch Design (3 patches in report)

- **Patch A**: Fix TUI lifecycle race — add timeout to "finishing context" guard, force-clear on abort
- **Patch B**: Add 60-second compaction timeout around summarization LLM call
- **Patch C**: Defensive checks in `serializeConversation()` and discard pending writes on abort
