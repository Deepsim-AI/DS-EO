## Fix implementer model display mismatch (09:17–09:31)

**Problem:** Webchat session header showed implementer running `ollama/ornith:35b` with `?/262k` tokens, but runtime was actually `ollama/qwen3.6:27b`.

**Root Cause:** `qwen3.6:27b` was missing from the registered Ollama models list in `~/.openclaw/openclaw.json` under `models.providers.ollama.models`. Runtime resolved correctly via agent-level config, but UI had no registry entry and fell back to `ornith:35b`.

**Fix:** Added `qwen3.6:27b` to the Ollama models registry and restarted gateway.

**Lesson:** Whenever an agent model is assigned but not in the registered models list, the UI shows incorrect/fallback info even though runtime resolution works. Keep the registry in sync with assigned models.
