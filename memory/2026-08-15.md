### CRITICAL BUG FOUND (not yet fixed) — MUST FIX before tests
Both strategy files resolve the agent model with:
```python
registry = AgentRegistry(workspace_root=self.workspace_root)
reg_result = registry.load()          # ← load() returns RegistryResult with agent=None
...
model_name = reg_result.agent.model    # ← AttributeError: None has no .model  (or NoneType)
```
`AgentRegistry.load()` (see `dispatcher/registry.py`) returns `RegistryResult(agent=None)`. The correct API is:
```python
registry = AgentRegistry(workspace_root=self.workspace_root)
registry.load()                       # populate cache
reg_result = registry.resolve(agent_id)   # returns RegistryResult with .agent set
if not reg_result.success or not reg_result.agent:
    return <failure StrategyResult>
model_name = reg_result.agent.model
```
