### Item 6: Update deploy_protocols.sh with Pre-Flight Integrity Check

Add to `/home/deepsim/ds-eo-openclaw/scripts/deploy_protocols.sh` before the deployment loop in **both** rollback and deploy modes:

```bash
# ─── Pre-flight Integrity Check (new — TASK_DS_EO_010) ──

PRE_FLIGHT_OK=true

if [ ! -d "${PKG_ROOT}/../.git" ]; then
    echo "⚠ WARNING: No .git found — deploy source cannot be verified." >&2
    PRE_FLIGHT_OK=false
else
    REPO_ROOT="$(cd "${PKG_ROOT}/.." && pwd)"
    uncommitted=$(cd "$REPO_ROOT" && git diff --stat HEAD -- '*.md' '*.sh' '*.json' '*.yaml' 2>/dev/null | wc -l)
    if [ "$uncommitted" -gt 0 ]; then
        echo "⚠ WARNING: $uncommitted uncommitted file(s) in deploy source." >&2
    fi

    staged=$(cd "$REPO_ROOT" && git diff --cached --stat 2>/dev/null | wc -l)
    if [ "$staged" -gt 0 ]; then
        echo "⚠ WARNING: $staged staged but uncommitted file(s)." >&2
    fi

    # Hard-fail: scripts being deployed have unstaged changes
    self_diff=$(cd "$REPO_ROOT" && git diff --stat HEAD -- 'scripts/deploy_protocols.sh' 2>/dev/null | wc -l)
    if [ "$self_diff" -gt 0 ]; then
        echo "✗ FATAL: deploy_protocols.sh has uncommitted changes. Commit before deploying." >&2
        PRE_FLIGHT_OK=false
    fi
fi
```

Then add at the top of both `--target` (deploy) and `--rollback` modes:

```bash
if [ "$PRE_FLIGHT_OK" != "true" ]; then
    echo "Deploy aborted due to integrity check failure." >&2
    exit 1
fi
```
